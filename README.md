# 🛍️ Сервистер мен ұсыныстар каталогі (React Native & Expo)

Бұл қосымша студенттерге және пайдаланушыларға арналған түрлі қызметтер мен ұсыныстарды қарауға, санаттар бойынша сүзгілеуге және хабарламалар алуға мүмкіндік беретін мобильді қосымша. Жоба **React Native**, **Expo** және **TypeScript** көмегімен жасалған.

## 🚀 Негізгі мүмкіндіктер

* **📂 Санаттар бойынша сүзгілеу:** «Барлығы», «Популярное», «Новинки», «Скидки» сияқты санаттар арасында жылдам ауысу (`useState` арқылы).
* **📦 Қызметтер тізіmi:** Әр түрлі ұсыныстар мен сервистердің сипаттамасы, бағасы және иконкалары көрсетілген карточкалар.
* **🔔 Хабарламалар экраны:** Пайдаланушыға келген жаңа хабарламалар мен оқылмаған хабарларды бөлектеп көрсету.
* **📞 Қолдау қызметіне жылдам өту:** Пайдалы сұрақтар мен көмек алуға арналған арнайы баннер.

---

## 🛠️ Қолданылған технологиялар

* **Frontend:** React Native, Expo
* **Тіл:** TypeScript
* **Стильдер:** StyleSheet (Flexbox)
* **Анимация/Скролл:** ScrollView (горизонтальды және вертикальды)

---

## ⚙️ Орнату және іске қосу

Жобаны өз компьютеріңізде іске қосу үшін келесі командаларды орындаңыз:

1. **Репозиторийді клондау:**
```bash
git clone <репозиторий-сілтемесі>
cd <жоба-атауы>

```


2. **Қажетті кітапханаларды орнату:**
```bash
npm install

```


3. **Қосымшаны іске қосу:**
```bash
npx expo start

```
